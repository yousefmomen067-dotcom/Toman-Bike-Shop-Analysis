# Toman Bike Shop | End-to-End Data Analysis Project

## Project Overview

This project analyzes bike shop data using SQL, Excel, and Microsoft Power BI to explore sales performance, revenue, profit, and rider behavior across 2021 and 2022.

The goal is to transform raw data into meaningful insights through data analysis, KPI calculations, and interactive visualization.

## Tools & Technologies

* **SQL Server:** Data querying, aggregation, and analysis.
* **Microsoft Excel:** Data preparation and spreadsheet analysis.
* **Power BI:** Interactive dashboard development and data visualization.

## Project Files

* `Excel_File_1.xlsx` — bike_share_yr_0 
* `Excel_File_2.xlsx` — bike_share_yr_1
* `Excel_File_3.xlsx` — cost_table
* `SQL_Analysis.sql` — SQL queries used for the analysis.
* `Toman_Bike_Shop.pbix` — Interactive Power BI dashboard.
* `dashboard_preview.png` — Dashboard screenshot.

## Key Performance Indicators

* Total Revenue: $15M
* Total Profit: $10M
* Profit Margin: 68.80%
* Total Riders: 3M

## Dashboard Analysis

* Monthly performance trends.
* Revenue and profit comparisons.
* Revenue by season.
* Registered and casual rider distribution.
* Hourly sales patterns by day of the week.

## Key Insights

* Summer generated the highest seasonal revenue.
* Winter generated the lowest seasonal revenue.
* Registered riders represented approximately 81.17% of total riders.

## Project Workflow

1. Prepare and review the source data.
2. Analyze the data using SQL queries.
3. Work with the Excel files for data preparation and analysis.
4. Build an interactive Power BI dashboard.
5. Present the main KPIs and business insights.

## Project Objective

This project demonstrates practical skills in SQL, Excel, Power BI, data analysis, and business intelligence.
